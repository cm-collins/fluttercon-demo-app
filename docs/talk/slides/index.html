2015–2019: a stutter you couldn't fix in Dart.

SkiaWorkaroundsImpellerThe trade
2015Sky, Flutter's predecessor, draws with Skia.
Dec 2018Flutter 1.0 ships on Skia, the 2D engine behind Chrome and Android's own UI.
May 2019Shader warm-up gets its own issue: #32170.
New effect on screen
Skia writes a shader
The driver compiles it on the raster thread
The frame misses its deadline
The user sees a stutter

Once per shader, per install. Hard to catch in development. Impossible to fix by optimising Dart.

2019–2021: working around it.

2019 · Warm up at startupDraw common shapes offscreen with shaderWarmUp.You had to guess the right draw calls.

2021 · Default removedThe default warm-up comes out; warm-up becomes opt-in.An admission that it couldn't scale.

The real fix "requires 0 extra effort from developers" and "handles all cases that may have never been encountered during any tests or warmups."

Take this home.

1

Demystify the engine. Skia compiles in the frame. Impeller compiles ahead, tessellates on the CPU and records explicit command buffers.

2

Profile low-level. About 4 ms UI, 4 ms raster, and the slowest thread sets your frame rate.

3

Tame your custom painters. Fewer points, fewer draws, no saveLayer you don't need. Prove every fix.

Impeller made performance predictable.
It didn't make expensive work free.
